# Disease Prediction System using Machine Learning

A machine learning–based disease prediction system that predicts the most probable disease from user-provided symptoms. The project includes data preprocessing, feature engineering, model training, evaluation, and an interactive prediction interface. Multiple machine learning algorithms are compared to identify the best-performing model, making the system suitable for healthcare analytics and educational purposes.

## Features

* Predicts diseases based on user symptoms
* Data preprocessing and cleaning
* Multiple machine learning models for comparison
* Model performance evaluation using standard metrics
* Saves the trained model for future predictions
* Interactive notebook demonstrating the complete workflow
* Easy to extend with additional diseases and symptoms
